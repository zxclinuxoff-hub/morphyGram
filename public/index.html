Telegram, который
помнит то, что удаляют

MorphyGram — тёмный веб-клиент Telegram с памятью. Сообщения, удалённые собеседником, остаются в чате с меткой «удалено». Правки не затирают историю. Одноразовые медиа сохраняются в момент получения. Ставится на главный экран iPhone и Android как приложение.

Возможности

☠

Анти-удаление

Собеседник удалил сообщение? В MorphyGram оно останется — перечёркнутое, с красной меткой «удалено». Клиент ловит событие удаления и сохраняет содержимое, которое уже дошло до вас.

✎

История правок

Каждое отредактированное сообщение хранит все свои версии. Значок «изменено» кликабелен: открывается список предыдущих текстов с временем каждой правки.

⏱

Одноразовые медиа

Фото и видео с таймером исчезновения скачиваются сервером сразу при получении — и остаются доступными у вас, с меткой «одноразовое».

▣

Установка на «Домой»

Это PWA: добавляется на главный экран iPhone и Android без App Store и Play Market. Запускается на весь экран, как нативное приложение, с вашей иконкой M.

⛨

Сессии только в памяти

Сервер не пишет сессии на диск: они живут в оперативной памяти и исчезают при перезапуске. Вход — только под собственным аккаунтом, переключателя между аккаунтами здесь нет и не будет.

☾

Ночная смена

Чёрная кожа, кровь и золото. Интерфейс создан для ночной работы: тёмные поверхности, никаких белых вспышек, красная подсветка событий.

Инструкция по установке

MorphyGram — это сайт-приложение (PWA). Чтобы «установить телегу», достаточно добавить этот сайт на главный экран.

  1. Откройте этот сайт в Safari — именно Safari, не Chrome (ограничение iOS).
  2. Нажмите кнопку «Поделиться» — квадрат со стрелкой вверх внизу экрана.
  3. В списке выберите «На экран “Домой”» (Add to Home Screen).
  4. Имя оставьте MorphyGram и нажмите «Добавить».
  5. На главном экране появится иконка M — запускайте как обычное приложение.
  1. Откройте сайт в Chrome (или другом браузере на Chromium).
  2. Нажмите меню ⋮ справа вверху.
  3. Выберите «Установить приложение» или «Добавить на главный экран».
  4. Подтвердите — иконка MorphyGram появится среди приложений.
  1. Откройте сайт в Chrome / Edge / Opera.
  2. В адресной строке справа нажмите значок установки (монитор со стрелкой).
  3. Либо: меню браузера → «Установить MorphyGram…».
  4. Приложение откроется в отдельном окне без адресной строки.
После установки первый вход делается один раз: номер → код из Telegram → (если включен) облачный пароль. Пока сервер не перезапустился, страница входит автоматически.

Честно об ограничениях

Анти-удаление работает, пока клиент онлайн. Если сообщение удалили, пока сервер был выключен или вы не открывали чат после последнего запуска — поймать его уже нечем: Telegram не отдаёт удалённое задним числом.
Одноразовые медиа не гарантируются. Обычно скачивание срабатывает, но Telegram может не отдать файл — тогда появится пометка «недоступно».
Это неофициальный клиент. Вход идёт через ваш собственный api_id/api_hash (my.telegram.org). Никакой админ-панели и доступа к чужим аккаунтам в коде нет — принципиально.
Память сервера. Сессии и кэш удалённых сообщений хранятся в RAM и стираются при перезапуске (на бесплатном тарифе Render — при засыпании). Это плата за приватность.
